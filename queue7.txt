# MFL 졸업논문 7차 실행 큐 (10/13 준비): 검토–적응 루프 반복 (A 모델, 2·3회차). 약 1시간 (GPU 40분 + CPU)
#   1회차(queue6)의 적응 모델 예측으로 다음 200장/배관을 고르고(누적 400 → 600장/배관), 공식 모델(A_s1)에서 같은 설정으로 다시 적응한다.
#   평가는 선택 집합을 모두 뺀 공통 집합(2회차 11,740장, 3회차 10,740장)에서 기준·1회차·2회차·3회차·무작위 모델을 같이 평가한다.
# 실행: python -m mfl_thesis.run_queue queue7.txt   (중단되면 같은 명령으로 재개)
# 끝나면: python pack_1012c.py  → results_1013_loop.zip 올리기
