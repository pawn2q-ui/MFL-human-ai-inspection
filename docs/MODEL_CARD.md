# 모델 카드 — MFL 결함 탐지기 A (공식 프로토콜 모델) + 판단보류 헤드
Model card: MFL defect detector "A" (official-protocol YOLOv8s trained on PipeMFL-240K pipeline-level split) with a deferral head and a review-and-adapt recipe.

| 항목 | 내용 |
|---|---|
| 모델 이름 | `A_s1` (논문 조건 A, 시드 1) — 운영 권고 모델. 같은 레시피의 시드 0 모델 `A_s0`, 적응 모델 `A_s1_adsel200`(검토 대상 200장/배관으로 5 에포크 적응) |
| 과제 | 가스배관 MFL(자기누설) 영상의 결함·구성요소 객체탐지 (12 클래스: 손상 4종 MTL·CRC·GWA·SWA + 구성요소 8종) |
| 구조 | YOLOv8s (ultralytics 8.4.172), 파라미터 약 1,120만 개, 약 28.6 GFLOPs @640, COCO 사전학습 가중치에서 시작 |
| 입력 | 5 m 구간 MFL 영상 5,000×2,400 px(3채널) → 2,400 px 정사각 창(배관 둘레 전체 포함) → 640×640. 학습 창 2개(x = 0, 2,600), 추론 창 3개(간격 1,300 px), 창 사이 예측은 클래스별 NMS(IoU 0.5)로 병합 |
| 출력 | 원본 좌표 바운딩박스(클래스·신뢰도) + 배관 공칭 외경으로 환산한 결함 실제 크기(mm; 세로 1 px = πD/2,400) + 영상 단위 검토 우선순위 점수와 검토 권고 |
| 만든 사람 | 박지훈 (중앙대학교 에너지시스템공학부 발전기계전공, 지도교수 양승화), 2026 |
| 라이선스 | 코드 MIT. 학습 가중치(.pt)는 ultralytics(AGPL-3.0)로 학습되었으므로 AGPL-3.0을 따릅니다 |

## 1. 용도

- 의도한 용도: ILI 판독의 **앞단 선별기**. 탐지기가 모든 영상에 결함 상자를 제안하고, 영상 단위 점수로 검토 우선순위를 매겨 검사원이 볼 영상(검토 예산)을 고른다. 검토 결과(확정 라벨)는 다음 적응 자료가 된다.
- 의도하지 않은 용도: 사람의 판독을 대체하는 단독 판정. 처음 보는 배관에서 MTL 재현율은 0.37 수준이며(아래), 원주 용접 이상(GWA)은 사실상 탐지하지 못한다.

## 2. 학습 자료

- PipeMFL-240K (Qu et al., KDD 2026) 공식 시험 묶음 48,064장(11개 실배관)을 **배관 단위**로 재분할.
- 학습 배관 E(610 mm), G(711), H·I·K(813) = 31,742장 → 양성 창 중심 타일 캐시 9,534개(양성:빈 ≈ 9:1, JPEG 품질 92). 검증 배관 F(711) 1,582장 → 783 타일.
- 시험 배관(학습에 없음): A·B·C(457 mm), D(508 mm) — 학습 범위 밖 관경, J(813 mm) — 같은 관경의 새 배관. 각 시험 배관에서 200장을 적응용으로 분리하여 평가에서 제외(평가 13,740장).
- 라벨은 데이터셋 제공자의 전문가 주석. 미탐·오탐은 이 주석에 대한 상대적 개념이다(라벨 없는 강한 신호가 오탐으로 집계될 수 있음).

## 3. 학습 설정

| 항목 | 값 |
|---|---|
| 에포크 / 배치 / 입력 | 60 / 16 / 640 (조기 종료 patience 20, 검증 mAP50 최고 에포크 선택) |
| 최적화 | ultralytics 기본(SGD, lr0 0.01, momentum 0.937, weight decay 5×10⁻⁴, 워밍업 3 에포크), AMP, rect 배치 |
| 증강 | ultralytics 기본값(모자이크·HSV·좌우 반전, 등방 배율 0.5) |
| 시드 | 0, 1 (deterministic) |
| 하드웨어 | NVIDIA RTX 2060 Super 8 GB 1장, Windows, PyTorch 2.11 (CUDA 12.8). 시드당 약 1.7 h |
| 적응(미세조정) | AdamW lr0 5×10⁻⁴, 워밍업 0, 백본 10층 고정, 5 에포크, 배치 16, last.pt 사용. 자료 = 검토 대상 상위 200장/배관(라벨 미사용 선택) |

## 4. 성능 (운영 임계값 0.25, IoU 0.5 일대일 대응)

검증 배관 F (학습에 없는 배관, 같은 관경군; 시드 0 모델): MTL 재현율 0.51, 정밀도 0.49, AP50 0.36.

시험 배관 5개 (처음 보는 배관, `A_s1`):

| 범위 | MTL 재현율 | MTL 정밀도 | MTL AP50 (≥0.25 / 전체 곡선) | 비고 |
|---|---|---|---|---|
| 전체 (n = 12,633) | 0.373 | 0.374 | 0.190 / 0.258 | 오탐 7,882 |
| 457 mm A·B·C (관경 외삽) | 0.37 / 0.14 / 0.27 | 0.23 / 0.35 / 0.40 | — | 그룹 재현율 0.26 |
| 508 mm D (관경 외삽) | 0.51 | 0.28 | 0.20 | 813 mm보다 높음 |
| 813 mm J (배관만 미관측) | 0.45 | 0.53 | 0.30 | |

- 같은 정밀도 비교(PR 곡선 보간): 정밀도 0.30에서 재현율 0.45(시드 1)·0.43(시드 0) — 관경 보정·타일 조건(0.28–0.39)보다 높다(논문 표 5-5).
- 클래스별: SWA 재현율 0.12, CRC ≈ 0(군집 라벨이라 박스 평가 부적합), GWA 0.00(모든 조건 공통 한계).
- 결함 길이별 POD: 어느 조건도 POD 0.9(a90)에 이르지 못함(최대 0.72). 길이 구간별 POD는 논문 5.2절.

## 5. 판단보류 헤드 (학습 없음, 탐지기 출력만 사용)

영상마다 운영 임계값 이상 검출 수 `n_pred`(동점은 임계값 미만 약한 검출의 최대 신뢰도 `sub_thr_max`로 가름), 또는 배관 안 순위 백분율 합 `combo`를 계산해 상위부터 검사원 검토 대상으로 보류한다.

| 검토량 (영상 수 기준) | 자동 영역 잔여 미탐률 (n_pred / combo) | 무작위 보류 | AUROC (n_pred) |
|---|---|---|---|
| 0% | 0.715 | 0.715 | 0.77 |
| 5% | 0.593 / 0.584 | 0.680 | |
| 10% | 0.510 / 0.505 | 0.644 | |
| 20% | 0.389 / 0.387 | 0.573 | |

검사원이 보류 영상의 미탐을 50%만 찾아내도 20% 검토의 잔여 미탐은 0.55로 무작위 보류의 상한(0.57)과 같다. 박스 수 기준으로는 어떤 점수도 무작위보다 효율적이지 않으므로 검토 예산은 영상 수로 정의한다(논문 5.5.1절).

## 6. 검토–적응 루프 (`A_s1` → `A_s1_adsel200`)

공통 평가 집합 12,740장(적응·선택 집합 제외, MTL 정답 박스 9,114개): 기준 → 무작위 200장/배관 적응 → 검토 대상 200장/배관 적응.

| | MTL 재현율 | 정밀도 | 오탐 | AP50 (≥0.25) | AP50 (전체 곡선) |
|---|---|---|---|---|---|
| 기준 `A_s1` | 0.366 | 0.372 | 5,616 | 0.189 | 0.258 |
| 무작위 200장 | 0.301 | 0.520 | 2,538 | 0.210 | 0.334 |
| 검토 대상 200장 | 0.346 | 0.503 | 3,113 | 0.244 | 0.353 |

검토 대상 200장/배관에는 손상 박스 4,408개(무작위 1,412개의 3.1배)가 들어 있었다. 무작위 적응은 SWA 재현율을 0.109→0.005로 무너뜨렸고 검토 대상 적응은 0.123을 유지했다.

## 7. 속도와 자원

- 추론: 5 m 영상 한 장(창 3개) 0.09 s — RTX 2060 Super, FP16. 100 km(약 2만 장) ≈ 30분. CPU만 있는 노트북에서도 영상당 1–2초 수준(추정; 시연 가능).
- 적응 1회(5 에포크, 1,000장): 수 분. 전체 연구의 학습 시간 약 70 GPU시간은 운영에 필요 없다.
- 입력 요구: 영상 파일 + `pipes.csv`(배관 ID, 공칭 외경). 가중치 파일 약 22 MB.

## 8. 한계와 주의

- 단일 모델 규모(YOLOv8s), 시드 2개, 시험 배관 5개, 관경 외삽은 큰→작은 한 방향. 결론은 이 자료 범위 안에서 유효하다.
- 절대 성능이 낮다(처음 보는 배관 설정 + 소형 모델). 판단보류 효과(20% 검토 시 잔여 미탐 40–48% 감소)는 본 연구의 다섯 모델에서 일관되었으나 더 큰 모델에서도 같다는 증거는 아직 없다.
- 검사원 효과는 상한 가정(보류 영상의 미탐을 모두 찾음)이며 검토 시간은 측정하지 않았다.
- 강종·벽 둑께·자화 조건 등 재질·장비 정보는 데이터셋에 없어 보정하지 못했다.

## 9. 파일과 재현

- 가중치: GitHub Releases (`A_s1_best.pt`, `A_s1_adsel200_last.pt`; AGPL-3.0). 저장소 코드에는 포함되지 않는다.
- 재현: `queues/queue.txt`(타일 캐시·학습) → `queue2.txt`(추론·평가·판단보류) → `queue5.txt`·`queue6.txt`(같은 정밀도 비교·검토 대상 적응). 자세한 순서는 `README.md`, `docs/PACKAGE_GUIDE.md`.
- 시연: `python -m mfl_thesis.demo --image <영상 또는 폴더> --diameter <공칭 외경 mm> --model A_s1_best.pt --out demo_out` → 결함 상자(mm)·검토 권고·`review_queue.csv`.
